# basic_html_website
## Présentation du site
Ce site est un site fictif qui a pour but de me faire pratiquer sur la création d'un site en HTML et CSS, pour cela j'ai découvert les notions de tableau notamment avec la balise table qui englobe les balises tr pour les lignes et td pour les colonnes, j'ai aussi pu m'améliorer en positionnement d'éléments avec flexbox pour pouvoir créer et intéger les box de la dernière section "Reviews".
